# Definition of done (starting point: adapt it for your team)

A story is **done** when:

- [ ] Code is on `main` via a reviewed merge request (session 02)
- [ ] Unit tests cover the new logic, and CI is green (sessions 06–07)
- [ ] Validation and reconciliation checks run and pass on test data (sessions 08, 13)
- [ ] Logging shows row counts and decisions at each step (session 09)
- [ ] The data dictionary and source-to-target mapping are updated (session 14)
- [ ] No real data, credentials or outputs are committed (session 02)
- [ ] Acceptance criteria are demonstrated to the product owner
- [ ] It can be re-run safely for any date (idempotent) (sessions 13, 15)
